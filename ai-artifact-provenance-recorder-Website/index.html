ai-Artifact-Provenance-Recorder

Records the build steps (commands, versions) that created an artifact, computes the artifact hash, and writes both into a JSON provenance file that can be used to check the artifact's lineage later.

Open the repo Usage

A verified example

python3 main.py report.pdf --provenance_file provenance.json --command "make build" --version "1.0"

This writes provenance.json with the artifact path, a UTC creation stamp, the build step, and the sha256 hash of the file.

Usage and parameters

python3 main.py <artifact_path> [--provenance_file FILE] [--command COMMAND] [--version VERSION] [--hash_algorithm ALGORITHM]
artifact_pathpath to the artifact (required). A missing artifact logs an error and exits 1
--provenance_filename of the provenance file (default: provenance.json)
--commandcommand executed to build the artifact
--versionversion of the tool used to build the artifact
--hash_algorithmhashing algorithm name accepted by Python hashlib (default: sha256)
-h / --helpshow help and exit

Hashes only, nothing verified

This recorder writes down commands, versions, and the artifact hash. It records hashes only: it does not verify digital signatures, and it does not compare the artifact against an expected hash. The registry entry is a record of how the artifact came to be, not a proof about it.

Requirements

Python 3 with only the standard library. This repository has no third party dependencies.
