ENTRY 1

What Gets Recorded

ai-Artifact-Provenance-Recorder records the build steps that created an artifact, meaning the commands and versions involved, computes the artifact hash, and writes both into a JSON provenance file, so the artifact lineage can be checked later.

Hashes Only, Nothing Verified

It records hashes only: it does not verify digital signatures, and it does not compare the artifact against an expected hash.

ENTRY 2

Nothing Borrowed

Python 3, standard library only, no third party dependencies in this repository.

ENTRY 3

a Completed Entry

Install by cloning:

git clone https://github.com/ShadowGuard-AI/ai-artifact-provenance-recorder

The verified example, exactly as documented:

python3 main.py report.pdf --provenance_file provenance.json --command "make build" --version "1.0"

It produces a provenance.json holding the artifact path, a UTC creation stamp, the build step, and the sha256 hash of the file.

ENTRY 4

The Fields and Their Resting Values

python3 main.py <artifact_path> [--provenance_file FILE] [--command COMMAND] [--version VERSION] [--hash_algorithm ALGORITHM]

artifact_path is required: the path to the artifact. A missing artifact logs an error and exits 1.

--provenance_file rests at provenance.json.

--command records the command executed to build the artifact.

--version records the version of the tool used to build it.

--hash_algorithm rests at sha256 and accepts any algorithm name Python hashlib accepts.

-h and --help show help.
